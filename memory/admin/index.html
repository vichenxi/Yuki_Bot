研究课题（雪听来的）

主方向是 Group HRT（人机信任），研究 mediation 过程中信任的建立、崩塌与修复。用 social presence 和 ontological framing switches 串起工具性信任和社会参与者性信任，研究两者之间的 trade-off。

方法：主观量表 + behavior analysis + 生理数据对齐，拍视频事后标注关键节点。声音刺激（高于基线 ≥20dB）作为崩塌触发标记点。
